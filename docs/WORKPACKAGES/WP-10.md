## What to build

```go
type Config struct {
    Policy cpa.Policy                                  // DefaultPolicy
    ClearAfterS, StaleAfterS, LiveMaxAgeS float64      // 3, 15, 10
    Zones []*zones.Zone; ZonePolicy zones.Policy        // PressureUncertaintyM 250
    MismatchSeverity, IdentificationSeverity core.Severity   // warning, critical
    GridCellM float64                                   // >= Policy.NeighbourRadiusM; default 1000
}
type Track struct {
    ID string; Pos core.LatLon; AltAMSLM *float64; AltSource core.AltSource
    VNMS, VEMS, VDMS float64; Flying *bool               // nil = unknown = not flying (C-05)
    CapturedAtS, RxAtS float64; SourceTS *float64; Backlog bool
    Source, Station string; Transmitter *string; Identified *bool
    Identification *core.Identification; Env zones.Env
}
type Alert struct{ Key, Kind string; Severity core.Severity; Aircraft []string; Detail map[string]any; RaisedAtS, LastTrueS, LastFalseS float64 }
type ClearReason string  // "resolved", "stale", "source_disabled"
type Cleared struct{ Alert; Reason ClearReason }
type Events struct{ Raised []Alert; Cleared []Cleared }
type Monitor struct{...}
func NewMonitor(c Config) *Monitor
func (m *Monitor) Observe(tr Track, wallS float64) Events
func (m *Monitor) Tick(wallS float64) Events
func (m *Monitor) SwitchSource(st sources.State, wallS float64) Events
func (m *Monitor) Drop(id string, reason ClearReason, wallS float64) Events
func (m *Monitor) Active() []Alert
func (m *Monitor) Counters() *core.Counters
```

Rules, each pinned by named cases:

- **Admission** (T-03, T-04, T-05, B-11), counted and ignored: `Backlog`
  -> `rejected_backlog` (`backlog-raises-nothing-then-live-alerts`,
  `backlog-raises-no-mismatch`); `wallS - RxAtS > LiveMaxAgeS` ->
  `rejected_late` (`late-delivery-not-evaluated`; the bound is on the
  rx leg, never on `captured_at`: `station-clock-skew-costs-no-alert`);
  a sample older on its own source clock than the one held for the same
  aircraft and not received later -> `rejected_out_of_order`
  (`out-of-order-sample-ignored`; `SourceTS` = `captured_at_s +
  station_clock_offset_s` in the test); a disabled source ->
  `rejected_source_disabled`.
- **Flying** (C-05): `Flying == nil || !*Flying` -> the aircraft is held
  but never paired or zone-judged (`on-the-ground-raises-nothing`); a
  disarm clears its conflicts as `stale` (`disarming-clears-as-stale`,
  the recorded old behaviour; plan §11 gap 4). The mismatch alert is
  judged on the ground too (`mismatch-raised-on-the-ground-too`).
- **Conflicts**: on each live sample, pair the aircraft with every
  neighbour from the grid within `NeighbourRadiusM` (`cpa.Grid.Near` then
  `cpa.Evaluate`); never pair two tracks of the same `Transmitter` when
  one is `Identified == false` (I-02, `unidentified-and-serial-of-same-
  transmitter-never-pair`); two identified serials on one transmitter do
  pair (I-04). Key = `conflict:` + sorted ids. Detail: `t_cpa_s`,
  `d_cpa_horizontal_m`, `d_alt_at_cpa_m`, `d_horizontal_now_m`,
  `vertical_separation_known` (names as the vectors; rounded to 0.1 by the
  test). Severity critical. A pair `Judged == false` neither refreshes nor
  shows false (`silent-neighbour-ends-stale-never-resolved`,
  `hysteresis_rule`).
- **Raise once, refresh silently** (C-06): `raised-once-not-every-tick`.
  Clear `resolved` when `(last shown false) - (last shown true) >
  ClearAfterS` (`resolved-after-hysteresis`, `diverging-clears-resolved-
  once-past-minimum`, `reporting-neighbour-can-resolve`); clear `stale`
  when an aircraft has not been heard for `StaleAfterS` on `Tick`
  (`silent-aircraft-cleared-stale-by-tick`, `silence-does-not-clear-
  before-stale`); when both hold at once, evidence outranks silence
  (`evidence-outranks-stale`). A clear carries the alert's current detail
  (C-14).
- **Severity change is a new raise** under the same key (C-07,
  `severity-change-is-raised-again`): the vector shows a raise at each
  change and no clear in between.
- **Zones** (T-09, Z-09, Z-10, R-09): for each candidate zone
  (`zones.Index`), `ContainsHorizontally`, `AppliesAt(CapturedAtS)` (the
  test maps seconds to `2026-10-01T10:30:00Z + captured_at_s`? No: read
  `zone-stops-applying-clears` and `applicability-at-placed-time-not-
  arrival`: the applicability windows are `2026-10-01T10:00:00Z` to
  `11:00:00Z`; derive the epoch the generator used from those two cases
  and document it in the test), then `zones.JudgeVertical`; key =
  `zone:<id>:<aircraft>`; counters `zone_checks_not_evaluated`,
  `zone_limits_not_judged` propagate from `zones.Result`. Entering and
  leaving (`zone-enter-and-leave`) clears `resolved` after hysteresis.
- **Identification** (G-02, G-03): an `Identification` with `Mismatch`
  raises `identification_mismatch` (warning) on every live message,
  cleared by the aircraft's own silence (`stale`); an incident status
  (`IncidentStatus()`) inside an incident zone (`IncidentZone()`) raises
  `identification` (critical) beside the zone alert and clears with it
  (`unidentified-in-prohibited-zone-raises-identification`). Details:
  `status`, `identification_reason`, plus the zone's `identifier` and
  `restriction` for the zone-bound one.
- **Source switches** (B-11): `SwitchSource` with a state that disables a
  type or instance drops those aircraft at once and clears their alerts
  as `source_disabled` (`source-disabled-clears-with-its-own-reason`,
  `one-station-off-drops-only-its-aircraft`); later samples from the
  disabled source are `rejected_source_disabled`; re-enabling admits
  again without replaying.
- **Isolation** (C-09): a failing zone or neighbour evaluation (error,
  non-finite) neither refreshes nor clears what it could not evaluate and
  does not lose the other checks' results.
- **Republish** (C-08): `Active()` is the replay set; the caller
  republishes every second. `Drop(id, reason)` lets the caller clear with
  `flight_ended`/`landed` (plan §11 gap 4).
- Bounded (E-10): a cap on tracked aircraft with oldest eviction counted;
  not safe for concurrent use (one monitor per cell set); document.

## Vector test (`alerting/vectors_test.go`)

`config{clear_after_s?, stale_after_s?, neighbour_max_age_s?,
live_max_age_s?, zones?[]}` over the header `policy` and the description's
defaults; `steps[]{t_s, op: observe|tick|switch_source, aircraft?,
source_type?, instance_id?, enabled?}`. Aircraft fields and defaults from
the description: `id`, `lat_deg`, `lon_deg` (`north_m`/`east_m` are
provenance: decode and ignore), `alt_amsl_m` (550), `vn`/`ve`/`vd` (0),
`flying` (true), `captured_at_s` (t_s), `rx_at_s` (captured_at_s),
`station_clock_offset_s` (0; `SourceTS = captured_at_s + offset`),
`backlog`, `source` (relay|remote_id), `station`, `alt_source`,
`identification`, `transmitter`, `identified`. Zones come as ED-269
features (`ed269.ParseZone` -> `zones.FromED269`); `Env` is
`GroundNotConfigured` with no undulation (the vectors use AMSL limits
only). Compare `per_step[i].raised/cleared` as unordered sets of (kind,
severity, aircraft sorted, detail with floats to 0.1, reason), then
`active_after` and `counters`.
