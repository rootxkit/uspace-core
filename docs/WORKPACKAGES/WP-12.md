# WP-12: `ed318`, `f3411`, `f3548` (G-M2 standards types)

Branch `feat/WP-12-standards-types`. Milestone G-M2 (`v0.2.0`). Owns
`ed318/`, `f3411/`, `f3548/` exclusively. Depends on WP-5 (`ed269`) and
WP-8 (`zones`) for the ED-318 mapping; `f3411`/`f3548` depend on `core`
only and can start first. Consumers: the CISP (publication), the
authority (zone authoring, DP), the USSP (SP, DSS), the ANSP
(constraints), the lab's conformance suite.

## Read first

1. `CLAUDE.md`, `docs/PLAN.md §3.14`, `§4` (tool dependencies allowed),
   `§10`, `§11` gap 7.
2. Spec `00 §2`, `00 §5` (glossary), `02 F1-F3, F6, F7`, `03 §1`

   values), `04 §3.4`, `04 §3.5` (F3548), `04 §4` (standards pinning,
   `extendedProperties`), `09 §1.4-1.6` (what is verified and what is not).
3. InterUSS `uas_standards` (pin a commit and record it in each package's

4. `ed269` (model, `Problems`, applicability), `zones.FromED269`.

## What to build

### `f3411`, `f3548`

Generate types only (no server/client scaffolding) with
`oapi-codegen` (`go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@<pinned> -generate types`)
into `f3411/types.gen.go` and `f3548/types.gen.go`, with `//go:generate`
lines and the `uas_standards` commit in a `SOURCE` file. Then by hand:

- Constants: F3411 `NetMinUasLocRefreshFrequencyHz = 1`,
  `NetMaxDisplayAreaDiagonalKm = 7`, `NetDetailsMaxDisplayAreaDiagonalKm = 2`,
  `NetMaxNearRealTimeDataPeriodSeconds = 60`,
  `NetDpMaxDataRetentionPeriodSeconds = 86400`, the response-time
  constants, `MaxSpeed 254.25`, `SpecialSpeed 255`, `SpecialHeight -1000`,
  `SpecialTrackDirection 361`; scopes `rid.service_provider`,
  `rid.display_provider`. F3548: the four `OperationalIntentState`
  values, `Cstr*`, `Oi*`, `TimeSync*`,
  `MaxRecoverableTimeInNonconformingStateSeconds`,
  `ExternalDataMaxRetentionTimeHours`, the `utm.*` scopes (all from the
  `uas_standards` constants; copy with their names).
- Special-value helpers (`04 §3.1`): `func (s RIDAircraftState)
  SpeedMS() *float64` (nil for 255; 254.25 means ">= 254.25"), `TrackDeg()
  *float64` (nil for 361), `func (h RIDHeight) DistanceM() *float64` (nil
  for -1000), `func (p RIDAircraftPosition) AltM() *float64` (nil for
  -1000); `OperationalStatus` to `odid.Status`-equivalent airborne rule
  (`Undeclared`, `Airborne`, `Emergency`, `RemoteIDSystemFailure` are
  airborne; `Ground` is not).
- Conversions to core: `func (p RIDAircraftPosition) LatLon() core.LatLon`;
  `func Volume4DToZonesEnvelope(v Volume4D) (geodesy.BBox, time.Time, time.Time)`
  for deconfliction prefilters; F3548 altitude `reference W84`, `units M`
  only (refuse others with a `*core.FieldError`).
- Round-trip tests: every example in `uas_standards` (and the InterUSS
  `dss` test fixtures you can fetch) unmarshals strictly, marshals, and
  unmarshals to an equal value; unknown fields are **ignored** on the
  wire (`02 §1`: "unknown fields ignored, never rejected, within a
  major"), so round-trip tests compare known fields and preserve
  `json.RawMessage` extras where the struct supports it.
- `FuzzUnmarshalRIDFlight`, `FuzzUnmarshalOperationalIntent`.

### `ed318`

```go
type Metadata struct{ CreationDateTime, UpdateDateTime time.Time; Originator string }
type Authority struct{ Name, Service, ContactName, SiteURL, Email, Phone *string; Purpose string; IntervalBefore *string }
type DataSource struct{ CreationDateTime, UpdateDateTime *time.Time; Author *string }
type DailyPeriod struct{ Day []string; StartTime, EndTime *string; StartEvent, EndEvent *string (BMCT, SR, SS, EECT) }
type TimePeriod struct{ Permanent string; StartDateTime, EndDateTime *time.Time; Schedule []DailyPeriod }
type UASZone struct{ Identifier, Country, Name string; Type core.ZoneType; Variant string; RestrictionConditions []string; Region *int; Reason []string; OtherReasonInfo, RegulationExemption, Message *string; ExtendedProperties map[string]json.RawMessage; LimitedApplicability []TimePeriod; ZoneAuthority []Authority; DataSource *DataSource }
type Geometry struct{ UomDimensions string; LowerLimit, UpperLimit *float64; LowerVerticalReference, UpperVerticalReference core.VerticalRef; HorizontalProjection json.RawMessage (GeoJSON Polygon or Circle extension) }
type Feature struct{ Type string; Geometry Geometry; Properties UASZone }
type FeatureCollection struct{ Type string; Metadata Metadata; Features []Feature }
type Limits = ed269.Limits
func Parse(data []byte, lim Limits) (*FeatureCollection, ed269.Problems)   // validate, never repair (06 T9)
func Export(fc *FeatureCollection) ([]byte, error)
func FromED269(doc *ed269.Document, meta Metadata) (*FeatureCollection, error)   // restriction -> type (spelling), applicability -> limitedApplicability, reason, authority -> zoneAuthority
func ToED269(fc *FeatureCollection) (*ed269.Document, error)                    // for export to legacy consumers; USPACE and daylight events refused with a reason
type Daylight interface{ Event(name string, day time.Time, at core.LatLon) (time.Time, error) }   // BMCT, SR, SS, EECT
func Applies(tp []TimePeriod, at time.Time, where core.LatLon, dl Daylight) (bool, error)         // reuses ed269 semantics; events resolved per day
func ToZones(fc *FeatureCollection, dl Daylight) ([]*zones.Zone, error)
```

Daylight: provide `ed318.NOAADaylight` (sunrise/sunset by the NOAA
algorithm, civil twilight for BMCT/EECT) in pure Go with a documented
accuracy, and a `FixedDaylight` for tests. A zone whose period uses an
event and whose location cannot resolve it is "not evaluated" with a
reason, never "applies".

### The ED-318 round-trip vector (G-M2 deliverable, plan §11 gap 7)

Write `vectors/testdata/ed318_roundtrip.json`: an authority-authored
FeatureCollection with every ED-318 property used (`USPACE` type with
`extendedProperties` carrying an Art. 3(4) requirements block, a `DAR`
reason, daylight events, `WGS84` reference as the extension), its
expected export, the ED-269 mapping of the mappable subset, and
refusals (unknown property, `REQ_AUTHORISATION` spelling in an ED-318
file, a period with an unknown event). List it under `local_files` in
`vectors/testdata/VERSION`, add it to the manifest and `TotalCases`,
regenerate `SHA256SUMS` (as WP-11 does); propose upstream.
